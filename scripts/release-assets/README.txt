РЕЕСТР ПИСЕМ — портативная программа (без установки)
============================================================

Это офлайн-программа для учёта исходящей и входящей корреспонденции: импорт
выгрузки из 1С, привязка писем друг к другу, темы, сроки и статусы, печать
реестра в PDF.
Для работы с реестром интернет и установка программы не требуются.
Переносите всю папку, включая Fixed Version WebView2; одного EXE недостаточно.


КАК ЗАПУСТИТЬ
------------
  Дважды щёлкните файл  reestr.exe
  Больше ничего устанавливать не надо — всё уже внутри этой папки.


КУДА ПОЛОЖИТЬ ПАПКУ
-------------------
  В любое место, куда разрешена запись: Рабочий стол, папка «Документы», флешка.
  НЕ кладите папку в  C:\Program Files  — туда запись запрещена, и база не создастся.


ПЕРВЫЙ ЗАПУСК
-------------
  При первом запуске программа сама создаст:
    • папку  data  и базу данных  data\registry.db
    • папку  imports  (куда класть файлы выгрузки)
  Всё хранится ВНУТРИ этой папки, рядом с программой.


КАК ЗАГРУЗИТЬ ДАННЫЕ (выгрузку из 1С)
------------------------------------
  1. Положите файл выгрузки (.txt) в папку  imports.
  2. В программе откройте экран «Импорт» и выберите этот файл.
  3. Программа покажет сверку (новые, уже в реестре, изменённые) — подтвердите импорт.
  За один раз импортируется один файл. Ведётся история импортов.
  Ваши темы, сроки и привязки при повторном импорте НЕ стираются.

  Тестовая выгрузка в комплект не включена. Используйте свою выгрузку из 1С.


ГДЕ ДАННЫЕ / КАК СДЕЛАТЬ РЕЗЕРВНУЮ КОПИЮ
----------------------------------------
  Все данные — в папке  data  (файл  registry.db).
  Резервная копия — скопировать всю папку программы в другое место.
  Перенос — скопировать всю папку на другой компьютер или флешку и запустить там.
  Перед копированием закройте программу, чтобы данные полностью записались на диск.


УДАЛЕНИЕ
--------
  Закройте программу, сохраните резервную копию данных и удалите папку.
  Отсутствие системных следов запуска Windows не гарантируется.


ПРЕДУПРЕЖДЕНИЕ WINDOWS ПРИ ПЕРВОМ ЗАПУСКЕ
----------------------------------------
  Windows может показать синее окно «Система Windows защитила ваш компьютер»
  (SmartScreen) — это нормально, потому что у программы нет цифровой подписи.
  Нажмите  «Подробнее», затем  «Выполнить в любом случае».


ПЕЧАТЬ В PDF
------------
  По кнопке «Печать» программа открывает системный диалог печати Windows.
  Выберите принтер  «Microsoft Print to PDF»  — Windows сама сохранит PDF-файл.
  Интернет не требуется.
  Примечание: на некоторых рабочих (корпоративных) компьютерах принтер
  «Microsoft Print to PDF» может быть отключён политиками — тогда обратитесь к ИТ-службе.


ИНТЕРНЕТ НЕ НУЖЕН
-----------------
  Файлы интерфейса, шрифты и база данных находятся локально.
  Проверка отсутствия сетевых обращений всего процесса, включая WebView2,
  должна выполняться отдельно при приёмке на целевом компьютере.
