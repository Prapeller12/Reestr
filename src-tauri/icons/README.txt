ИКОНКИ ПРИЛОЖЕНИЯ — обязательный ручной шаг перед первой сборкой bundle
========================================================================

`tauri build` (с упаковкой) требует набор иконок. Бинарные .png/.ico/.icns
в этот репозиторий не закоммичены. Перед первой сборкой сгенерируйте их одним
из способов:

СПОСОБ 1 (рекомендуется) — автогенерация из одного PNG 1024x1024:
    npm run tauri icon path/to/app-1024.png
  Команда создаст в src-tauri/icons/ весь набор:
    32x32.png, 128x128.png, 128x128@2x.png, icon.icns, icon.ico
  — ровно те пути, что перечислены в tauri.conf.json → bundle.icon.

СПОСОБ 2 — положить файлы вручную с теми же именами:
    32x32.png, 128x128.png, 128x128@2x.png, icon.icns, icon.ico

Примечание: для `tauri dev` и `tauri build --no-bundle` иконки не обязательны —
они нужны только при сборке инсталляционного bundle. Для PUBLIC-релиза проекта
(единый reestr.exe) значок exe берётся из icon.ico.
